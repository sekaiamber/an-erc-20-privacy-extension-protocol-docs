# 0012 视觉形象：秘密账簿，以一枚火漆印为标志

- 状态：Accepted（2026-10-14）。接受的是风格；dApp 留待之后详细完成
- 日期：2026-10-14
- 范围：家族（只涉及外观；不改行为，不加概念）

## 背景

[ADR-0011](0011-project-name-casata.zh-cn.md) 给项目定名 Casata，标志留作未决。dApp 现在用的还是组件库的默认主题，文档也没有标志。owner 要求项目有自己的风格，并打算用一件文艺复兴时期的雕塑作首页的开场。

有两条约束来自更早的决定。全称 Casata Segreta 容易被误读为对监管隐瞒，而家族做的恰恰相反（[ADR-0004](0004-regulatory-access-principles.zh-cn.md)）。另外，owner 不希望在不需要的地方增加家族级概念。

## 决策

1. **风格围绕一个意象：家族的秘密账簿**（*libro segreto*）。纸色底、墨色字，一个强调色，即封蜡红。时代取 1350 年到 1500 年前后的意大利，以佛罗伦萨为参照。具体色值和规则写在 [12 视觉风格](../12-visual-style.zh-cn.md)；外观以那份文档为准。

2. **封蜡红标记被封存的东西**，即密文金额或句柄，以及 Cicerone 的标签。owner 在 2026-10-14 补充：它也标记强烈的行动召唤，例如连接钱包、部署（[12 §3](../12-visual-style.zh-cn.md#3-颜色)）。除此之外不用。

3. **两个层次。** 账页层（所有要用的界面）是扁平的。器物层（印、雕塑）是写实的，只出现在首页、章节开头和 README 头图。一处例外由 owner 在 2026-10-14 定下：dApp 顶栏名字旁边渲染的印（[12 §6](../12-visual-style.zh-cn.md#6-印)）。器物与页面共用材料，共用一个左上方的光源，各配一行展签，只有一种动效。

4. **标志是一枚火漆印的印痕。** 纹章：马头盾上一个大写字母 C，上方一个环。字母是开口的哥特大写。铭文：`CASATA` 和 `SEGRETA`，顶部和底部各用一朵百合花隔开。没有冠冕，没有扶盾的动物，没有格言，没有年份。

5. **24 像素以下用扁平的标志**：封蜡红圆底上一面纸色的盾，盾里一个 C。

6. **印由仓库里的脚本画出**（`brand/seal/`），可以修改后重新生成。它不是一张手工制作的图片。

7. **字体**：标题用 EB Garamond，界面和正文用 Source Sans 3，地址和金额用 IBM Plex Mono。

8. **首页是一个独立的应用，与 dApp 分开**（2026-10-14 补充）。首页的雕塑为本项目制作，不取自现存作品，并且始终不展示全貌。理由见 [12 §7](../12-visual-style.zh-cn.md)。

9. **本 ADR 不决定的事**：错误提示的颜色；GitHub 组织、域名和商标（ADR-0011 留下的未决项）。

## 备选方案

- **书房与收藏（studiolo）**：装饰更多。owner 选了账簿。
- **现代极简**：与名字没有关系。
- **扁平的几何标志**（读作 C 的开口环，或密码盘）。最先画的是这个。owner 选了印，并要求它像真的蜡，里面是纹章。
- **Fraktur 或 Old English 的字母。** 更花。被否决：这些字体属于北欧一系，今天是纹身和帮派常用的字，而且它们的 C 容易读成 E。
- **闭口的伦巴第体 C**，是那个时代的写法。被否决：今天会读成 G。
- **拉丁文铭文** `SIGILLVM · CASATAE · SECRETAE`。它合乎真实印章的格式。owner 选了意大利文的名字。
- **铭文里带年份。** 随拉丁文铭文一起被否决；在意大利，十六世纪以前印章铭文里的年份很少见。
- **左右对分的盾**，一侧是字母，一侧是横条。被否决：它会被读成两家纹章合并。

## 后果

- 正面：名字、标志和界面讲的是同一个故事，而且讲的是记账，不是隐瞒。
- 正面：一种颜色只有一个含义。读者会知道红色表示封存。
- 负面：错误提示不能直接用红色，它的颜色还没有定。
- 负面：带纹章的印可能被看成自称贵族。纹章因此不带冠冕和扶盾的动物；也还没有核对它是否与现存纹章相近。
- 负面：渲染的印依赖 SVG 滤镜，只用 Chrome 渲染过。
- 负面：历史方面的依据是两部工具书和另一位审阅者的意见。有几处没有核实，列在 [12 §10](../12-visual-style.zh-cn.md)。
- 接下来要做的事：dApp 其余的页面；作为第二个应用的首页，以及为它制作的雕塑。
