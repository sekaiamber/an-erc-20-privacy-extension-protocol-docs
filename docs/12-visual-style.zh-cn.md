# 12 视觉风格

状态：`Draft`（2026-10-14）。决策记录：[ADR-0012](adr/0012-visual-identity.zh-cn.md)。印和画它的脚本：[`brand/seal/`](../brand/seal/README.zh-cn.md)。风格已接受；dApp 留待之后详细完成，见 §9。

本文说明 Casata 长什么样，以及为什么。范围包括界面、文档和项目的标志。它不给家族增加任何概念：Track、Variant、模块都不变。

## 1. 立意

整个风格围绕一个意象：**家族的秘密账簿**（*libro segreto*）。中世纪晚期到文艺复兴时期的意大利商号，在普通账簿之外另有一本不给外人看的账：合伙人的出资、各自的份额、真实的利润。家族里的代币做的是同一件事。余额和金额有记录，不公开，只对持有相应密钥的人打开。监管方在设计上就是其中之一（[ADR-0004](adr/0004-regulatory-access-principles.zh-cn.md)）。

时代取 1350 年到 1500 年前后的意大利，以佛罗伦萨为参照。

这个风格不包括：黑帮意象、金色渐变、霓虹或「加密圈」式的发光、做旧的纸张贴图、带冠冕或猛兽的纹章。「Segreta」绝不能读成对监管隐瞒。名字单独出现的地方，旁边的文字都要写明监管接入是内置的（[ADR-0011](adr/0011-project-name-casata.zh-cn.md)）。

## 2. 两个层次

所有视觉元素都属于两个层次之一，两者分开使用。

| 层次 | 包括什么 | 样子 | 出现在哪里 |
| --- | --- | --- | --- |
| **账页** | 所有要用的界面：代币页、部署页、表单、表格、文档 | 扁平。字体、横线、一个强调色。没有阴影，没有渐变，没有光 | 所有地方 |
| **器物** | 印；首页上的雕塑 | 写实，有光影。数量少，尺寸大 | 首页、章节开头、README 头图 |

把两个层次连在一起的有四条。

1. **材料。** 纸、墨、蜡，器物另加石。雕塑保持石头本色，色调往纸色靠。封蜡红始终是页面上唯一的饱和色。
2. **一个光源。** 所有器物都是左上方来的柔光。印就是这样渲染的（`brand/seal/build.cjs`，方位角 225）。雕塑的照片或 3D 模型，按这个光来选或来打。
3. **展签。** 每件器物配一行等宽字：作品名、作者、年代、馆藏、许可。它就是博物馆的展签，署名和许可也写在这里。
4. **动效。** 只有器物可以动，而且只是随页面滚动而转动。页面本身不动：没有视差，没有弹跳。读者的系统要求减少动效时，器物是一张静止图。

器物不进入账页层。印在界面里只以扁平形式出现（§6）。

### 封蜡红的规则

封蜡红标记的是**被封存的东西**：以密文存储的金额，或代表这种金额的句柄（[07 §4](07-family-conventions.zh-cn.md)）。它也是 Cicerone 标签的颜色（§5）。除此之外不用。主按钮是墨色，不是红色。

上面各表里文字和底色的组合，对比度都不低于 4.5:1。这些数字是按色值手算的，没有在屏幕上测量。

## 4. 字体

| 角色 | 字体 | 说明 |
| --- | --- | --- |
| 标题 | EB Garamond，字重 500 | 中文标题：Noto Serif SC，或系统宋体 |
| 界面和正文 | Source Sans 3 | 中文：系统无衬线字体 |
| 地址、金额、版本号、选择器 | IBM Plex Mono | 表格里的金额右对齐 |
| 仅用于印的铭文 | Cinzel Bold | 以轮廓保存，不是界面字体 |

四款都以 SIL Open Font License 发布。Cinzel 核实过；另外三款是凭记忆，发布前要再确认。

圆角 2 到 3 像素。控件高度不低于 44 像素。

## 5. 母题

- **横线。** 单线分隔条目，双线收束一个标题或一组合计。不用别的边框或底色来强调。
- **封存记号。** 数值旁边一个封蜡红的小圆，表示这个数值是封存的。它就是印的扁平形式（§6）。
- **页边。** 讲解不放在卡片里，而是放在它所讲解的条目旁边的页边，用斜体衬线，上面是封蜡红的 *Cicerone* 标签。Cicerone 是向导的名字（[ADR-0011](adr/0011-project-name-casata.zh-cn.md)），页边是它说话的地方。窄屏上，批注跟在条目后面。

## 6. 印

项目的标志是一枚火漆印的印痕。

| 部分 | 内容 |
| --- | --- |
| 纹章 | 一个大写字母 C，上方一个环。不规定色彩：印只有一种颜色 |
| 盾 | 马头盾（*scudo a testa di cavallo*），十五世纪佛罗伦萨使用的盾形 |
| 字母 | 开口的哥特大写，为本项目绘制。意大利的印章铭文一直用哥特大写，直到文艺复兴后期 |
| 环 | 项目自己的图案，取自阿尔伯蒂密码盘的两个环 |
| 铭文 | 右侧 `CASATA`，左侧 `SEGRETA`，从顶部起顺时针读，罗马大写。两个词之间，顶部和底部各有一朵百合花 |
| 边 | 一道线、一圈珠、一道线 |

有意不加的：冠冕、扶盾的动物、格言、年份。冠冕意味着爵位；印章铭文里的年份，在意大利十六世纪以前很少见。

百合花在这里是词与词之间的装饰，这种用法很常见。它是普通的样式，不是佛罗伦萨那种带花蕊的百合，也没有放到盾面上。百合是佛罗伦萨城和法国王室的徽记；美第奇家族的纹章是圆球。

### 尺寸

| 尺寸 | 形式 |
| --- | --- |
| 48 像素及以上 | 渲染的印，`brand/seal/png/` 或 `casata-seal.svg` |
| 24 像素及以下 | 扁平版，`brand/seal/casata-seal-flat.svg`：封蜡红圆底上一面纸色的盾，盾里一个 C |

两者之间优先用扁平版。渲染的印在 32 像素以下只是一个红点。

渲染的印属于器物层（§2），不用在界面里。

## 7. 首页

首页是一个独立的应用，与 dApp 分开（owner，2026-10-14）。dApp 要派生密钥、连接钱包；首页要加载 3D 代码，以后还可能带别的脚本。两者放在不同的源下，首页上的任何东西都碰不到 dApp 的页面和存储。首页还可以做成静态站，两边也可以各自发布。两者共用本文：颜色、字体和印。

首页以一件雕塑开场，形式是 3D 模型。它不是任何现存作品的复制。它始终不展示全貌：视角随页面滚动在它上面移动，文字随着移动出现。它遵守 §2 的四条。目前还没有做，也还没有模型。

dApp 有自己的入口页。入口页上有渲染的印、名字，以及写明监管接入是内置的那一行。

## 8. 语气

文字朴素、准确。意大利语只用于专名：Casata、Casata Segreta、Cicerone。Track、Variant、模块保留英文名。界面文字遵守和文档相同的规则。

## 10. 依据

- 印章铭文的字体、起始记号和年份：《意大利百科全书》「Sigillo」条（见[参考资料](references.zh-cn.md)）。§6 里关于意大利哥特大写和年份的说法出自这里。
- 「casata」一词：Du Cange《中世纪与晚期拉丁语词典》「Casata」条（见[参考资料](references.zh-cn.md)）。
- 美第奇银行的秘密账簿，以及阿尔伯蒂约 1467 年的密码盘，只做过简单检索，依据是二手资料。对外引用前要再核对。
- §6 里关于百合花、佛罗伦萨的百合和美第奇纹章的说法是凭记忆写的，没有对照资料核实。
- 马头盾出现在 1440 到 1460 年代佛罗伦萨的说法，来自另一位审阅者，没有对照资料核实。
